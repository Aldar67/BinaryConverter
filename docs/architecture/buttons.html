Куда уходит нажатие кнопки

Сайт состоит из трёх частей. Каждая кнопка либо меняет картинку прямо в браузере, либо отправляет запрос на сервер, а сервер зовёт ядро, где живёт вся математика.

Три части сайта

Три типа кнопок

БРАУЗЕР

Только картинка

Данные уже есть в браузере. Меняется только то, что видно на экране.

кнопка → функция app.js → экран
GET

«Построить»

Браузер просит у сервера решение по шагам и рисует его на доске.

app.js → GET /api/… → Endpoints → Core → JSON → доска
POST

«Проверить»

Браузер отправляет ответ ученика, сервер пересчитывает и говорит, верно или нет.

app.js → POST /api/check → AnswerChecker → correct/hint
