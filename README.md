# Целые числа в системах счисления

Веб-тренажёр по переводу целых неотрицательных чисел между системами счисления с основаниями от 2 до 16. Приложение показывает каждый шаг решения, а ученик сам находит вклад разряда, очередной остаток и порядок записи цифр.

## Возможности

**Задача 1. Из системы b в десятичную (разрядное разложение)**
- Карточки цифр над разрядными весами (16², 16¹, 16⁰).
- Ученик находит вклад выбранного разряда, а сервер проверяет ответ.
- Поэтапное суммирование вкладов: полоса-сумматор и счётчик.

**Задача 2. Из десятичной в систему b (деление с остатком)**
- Деление уголком: остатки появляются рядом с вычислениями.
- Ученик находит очередной остаток, затем собирает запись числа в правильном порядке (остатки читаются снизу вверх).

**Общее**
- Основания от 2 до 16, числа от 0 до 4095.
- Обработка нуля и недопустимых цифр (неверный символ подсвечивается).
- Подсказки без готового ответа и полное решение по кнопке.
- Случайные задания.
- Светлая и тёмная темы, адаптивная вёрстка.

## Запуск

В терминале, в корневой папке проекта (где лежит `NumberSystems.sln`):

```bash
dotnet run --project src/NumberSystems.Web
```

Откройте в браузере адрес, который выведет консоль (по умолчанию `http://localhost:5137`). Остановить сервер: `Ctrl + C`.

### Запуск в Visual Studio

1. Откройте файл `NumberSystems.sln`.
2. Выберите стартовым проект **NumberSystems.Web**.
3. Нажмите ▶ (F5). Браузер откроется автоматически.

### Запуск тестов

```bash
dotnet test
```

## Архитектура

Три слоя. Вся математика живёт в ядре, браузер ничего не вычисляет.

```
Браузер (wwwroot)        index.html · styles.css · app.js
   │  JSON (fetch)       рисует шаги, анимирует, принимает ответы
   ▼
NumberSystems.Web        Minimal API: HTTP ⇄ вызов ядра
   │                     Result<T> → 200 или 400
   ▼
NumberSystems.Core       вся математика, без зависимостей от ASP.NET
```

### Ключевые решения

- **Алгоритмы возвращают шаги, а не только ответ.** Браузер рисует их как есть.
- **Ошибки ввода: `Result<T>`, а не исключения.** Ошибка содержит код, сообщение и позицию неверного символа.
- **Один валидатор на обе задачи.** Десятичный ввод разбирается тем же кодом с основанием 10.
- **Ноль без особого кода.** Цикл `do … while` даёт для нуля один шаг `0 = b·0 + 0` и запись «0».
- **Проверка без состояния.** Условие приходит в запросе, ответ вычисляется заново, ни сессий, ни базы данных.

## HTTP API

| Метод | Адрес | Назначение |
|---|---|---|
| GET | `/api/to-decimal?number=1A3&radix=16` | разрядное разложение: цифра, вес, вклад, сумма |
| GET | `/api/from-decimal?number=419&radix=16` | цепочка делений и итоговая запись |
| POST | `/api/check` | проверка ответа: `{kind, number, radix, index, answer}` |
| GET | `/api/exercise?direction=ToDecimal` | случайное задание (`ToDecimal` или `FromDecimal`) |

Ошибка ввода возвращает `400` с телом `{ "code": "...", "message": "...", "position": 1 }`.

Типы проверки (`kind`): `DigitContribution` (вклад разряда), `NextRemainder` (остаток деления), `DigitOrder` (порядок цифр).

Пример:

```
GET /api/to-decimal?number=1A3&radix=16
→ 200 { "value": 419, "terms": [ { "position": 2, "symbol": "1", "weight": 256, "contribution": 256, "runningSum": 256 }, ... ] }
```

## Тесты

59 автоматических тестов:
- разложение и деление: примеры, регистр, ведущие нули, ноль, коды ошибок;
- круговая проверка: все числа 0…4095 во всех основаниях 2…16 переводятся туда и обратно без потерь;
- проверка ответов (вклад, остаток символом и числом, порядок);
- API через `WebApplicationFactory`: коды 200/400, формат ошибки.

## Ограничения

- Только целые неотрицательные числа до 4095, основания 2–16.
- Эндпоинты визуализации отдают все шаги, поэтому ответ можно увидеть в инструментах разработчика браузера. Для тренажёра это допустимо.
- Шрифты подгружаются из Google Fonts; без интернета используются системные.
